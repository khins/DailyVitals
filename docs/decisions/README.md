# Engineering Decision Records

Decision records explain choices that materially shape behavior, safety, or maintainability. They are intentionally short and should describe the context and tradeoffs that existed when the decision was made.

## Adding a Decision

Use the next sequential number and include:

- Context
- Decision
- Consequences
- Alternatives considered

Do not rewrite an accepted decision to hide a later change. Add a new record that supersedes it.
